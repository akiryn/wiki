

# 浏览器
## 使用插件
使用浏览器插件如：Vimium，Vimium C，Surfingkeys，Tridactyl(仅支持firefox)。
Vimium，Vimium C上手简单好用，多浏览器支持，推荐。
这里主要介绍Firefox下使用Tridactyl。
### Tridactyl安装
Arch 官方仓库提供稳定版，Beta 通过上游链接安装，两者配置存储独立。
```bash
# sudo pacman -S firefox-tridactyl
# 我安装的是官方GitHub的Beta版本
# https://tridactyl.cmcaine.co.uk/betas/nonewtab/tridactyl_no_new_tab_beta-latest.xpi
paru -S firefox-tridactyl-native-bin
```

| 模式名称      | 对应场景          | 进入方式         |
| --------- | ------------- | ------------ |
| `normal`  | 正常浏览          | esc          |
| `insert`  | 输入文本          | i            |
| `ex`      | Tridactyl 命令行 | :            |
| `hint`    | Hint 模式       | f、F          |
| `visual`  | 文本选择          | v            |
| `ignore`  | 忽略模式          | Shift+Insert |
| `browser` | 浏览器级快捷键       | Ctrl+v       |
严格来说browser并不是一个模式
### 配置方式
默认进行的个性化配置会存在~/home/y~/.config/mozilla/firefox下
推荐创建`~/.config/tridactyl/tridactylrc`来管理所有个性化配置，每次保存后回到浏览器要执行`:source`


### normal常用快捷键
<C-,> 当前页面无法使用 Tridactyl，想回到能用它的页面时使用
<C\-v> 在 普通模式，想让网页处理下一次按键。
<C\-o>  在 忽略模式，想临时执行一次 Tridactyl 快捷键。

Navigating with the current page
```
jk hl ^/$ gg/G f/F/gF gi r/R yy yt ym [[/]] ]c/[c gu/gU gr zi/zo/zz <C-d>/<C-u> <C-f>/<C-b>
# g? Apply Caesar cipher to page
# g! Jumble words on page
```
Find mode
```
/<C-f> <C-g>/<C-G>
```
Bookmarks and quickmarks
```
A a M<key> go<key>/gn<key>/gw<key> m+字符 `+字符
```
Quickmark 将字符关联到 URL，适合高频网站；Bookmark 是 Firefox 普通书签；Mark 用于记录网页位置。
Marks
```
m+a-zA-Z `+a-zA-Z ``
```
Navigating to new pages
```
o/O t/T w/W p/P s/S H/L gh/gH
# gh/gH — go to the pages you have set with set home [url1] [url2] ...
```
Handling tabs处理标签
```
d u gt/gT    g^ 0R g0/g$ ga <C-^> b/B
```
Extended hint mode
```
;i/;I — open an image (in current/new tab)
;s/;a — save/save-as the linked resource
;S/;A — save/save-as the selected image
;p — copy an element's text to the clipboard
;P — copy an element's title/alt text to the clipboard
;y — copy an element's link URL to the clipboard
;# — copy an element's anchor URL to the clipboard
;r — read the element's text with text-to-speech
;k — delete an element from the page
;; — focus an element
;t 在新标签页打开当前标签页内链接，并立即切过去
```
### 主题样式
使用:colourscheme default设置内置主题为default或者使用其他外置主题，见下
```bash
:colourscheme --url https://raw.githubusercontent.com/dracula/tridactyl/main/dracula.css dracula
:colourscheme --url https://raw.githubusercontent.com/devnullvoid/tridactyl/main/themes/catppuccin-mocha.css catppuccin-mocha
```
也可以基于预设改
```bash
mkdir -p ~/.config/tridactyl/themes
curl -fL https://raw.githubusercontent.com/dracula/tridactyl/main/dracula.css \
  -o ~/.config/tridactyl/themes/dracula-compact.css
```
在 dracula-compact.css 追加内容，然后在~/.config/tridactyl/tridactylr写入`colourscheme dracula-compact`。
### Insert模式
| 快捷键          | 作用                |
| ------------ | ----------------- |
| `Esc`        | 取消输入框焦点并返回 Normal |
| `Ctrl+[`     | 同上                |
| `Ctrl+i`     | 使用外部编辑器编辑输入框内容    |
| 普通字母、数字      | 正常输入文本            |
| `Ctrl+c/v/x` | 通常保留原生复制、粘贴、剪切    |
可以在 `tridactylrc` 中添加：
```
set editorcmd kitty nvim
```
### ex-commands模式
选中候选项后，还可以依次按 **`Ctrl+O`、`y`、`y`** 复制它。按 **`Ctrl+O`、`t`** 可把候选项在后台标签页打开，按 **`Ctrl+O`、`w`** 可在新窗口打开。
以下是根据官方 `exmaps` 配置整理的内容。

| 快捷键                 | 作用                           |
| ------------------- | ---------------------------- |
| `Enter`             | 执行当前命令                       |
| `Ctrl+j` / `Ctrl+m` | 执行当前命令                       |
| `Esc` / `Ctrl+[`    | 关闭命令行                        |
| `Tab`               | 下一个补全项                       |
| `Shift+Tab`         | 上一个补全项                       |
| `PageUp`            | 向上移动 15 个补全项                 |
| `PageDown`          | 向下移动 15 个补全项                 |
| `↑`                 | 上一条历史命令                      |
| `↓`                 | 下一条历史命令                      |
| `Alt+b`             | 向后移动一个单词                     |
| `Alt+f`             | 向前移动一个单词                     |
| `Ctrl+e`            | 移动到行尾                        |
| `Alt+d`             | 向前删除一个单词                     |
| `Shift+Backspace`   | 向后删除一个单词                     |
| `Ctrl+u`            | 删除光标前的内容                     |
| `Ctrl+k`            | 删除光标后的内容                     |
| `Ctrl+f`            | 补全                           |
| `Ctrl+Space`        | 强制插入空格                       |
| `Space`             | 把高亮的命令名填入输入框，并加一个空格，以便继续输入参数 |
这套命令行编辑键主要借鉴的是 **Emacs / GNU Readline 风格**

|快捷键|作用|
|---|---|
|`Ctrl+o` 后按 `yy`|复制当前补全项|
|`Ctrl+o` 后按 `t`|在后台标签页打开当前补全项|
|`Ctrl+o` 后按 `w`|在新窗口打开当前补全项|
|`Ctrl+o` 后按 `x`|对所有补全项执行当前 Ex 命令|
|`Shift+Delete`|对当前补全项执行关闭标签页操作|
按 `b` 搜索已打开的标签页，然后使用 `Shift+Delete`，可以直接关闭当前选中的标签页。
### Visual模式
调整文本选区

|快捷键|作用|
|---|---|
|`h`|向后移动选区活动端一个字符|
|`l`|向前移动选区活动端一个字符|
|`j`|向下一行调整选区|
|`k`|向上一行调整选区|
|`w`|向前移动至下一个单词边界|
|`b`|向后移动至单词边界|
|`e`|向前移动至单词末尾附近|
|`0`|将活动端移动至行首|
|`$`|将活动端移动至行尾|
|`o`|交换选区的活动端|
|`=`|扩大选区至上层 DOM 元素|

对选区执行操作

|快捷键|作用|
|---|---|
|`y`|复制选中文本|
|`s`|在当前标签页搜索选中文本|
|`S`|在新标签页搜索选中文本|
|`#`|复制文本片段定位链接|
|`q`|为选中文本生成二维码|
|`Esc`|清除选区并退出|
|`Ctrl+[`|同 `Esc`|

数字前缀

与 Vim 类似，部分移动操作支持 Count（数字前缀）。

|快捷键|作用|
|---|---|
|`5l`|向前移动 5 个字符|
|`3h`|向后移动 3 个字符|
|`3w`|向前移动 3 次单词边界|
|`2j`|向下移动 2 行|
|`2k`|向上移动 2 行|
|`2=`|执行两次 DOM 选区扩展|


Visual 模式还会继承 Normal 模式中未被覆盖的按键映射。


### Ignore模式
`shift+esc`可以切换，`ctrl+o`临时进入

# PDF阅读器
## Zathura
Linux 上的 Vim 风格 PDF 阅读器

```bash
sudo pacman -S zathura zathura-pdf-mupdf zathura-cb zathura-djvu zathura-ps
```

|内容|文件格式|
|---|---|
|文档|PDF（`.pdf`）、XPS / OpenXPS（`.xps`、`.oxps`）|
|电子书|EPUB（`.epub`）、FictionBook（`.fb2`）、Mobipocket（`.mobi`）|
|扫描文档|DjVu（`.djvu`、`.djv`）|
|印刷和矢量文档|PostScript（`.ps`）、EPS（`.eps`）|
|漫画压缩包|`.cbz`（ZIP）、`.cbr`（RAR）、`.cb7`（7z）、`.cbt`（TAR）|
|单张图片|SVG、JPEG、PNG、BMP、TIFF|

https://man.archlinux.org/man/zathurarc.5.en
https://man.archlinux.org/man/zathura.1.en#MOUSE_AND_KEY_BINDINGS


| 按键                      | 操作                                |
| ----------------------- | --------------------------------- |
| `o`                     | 打开文件                              |
| `Space` / `Shift+Space` | 向下 / 向上滚动一屏                       |
| `Tab`                   | 打开 PDF 自带的目录，用 `j` / `k` 选章节，回车跳转 |
| `s` / `a`               | 适应窗口宽度 / 将整页放进窗口                  |
| `+` / `-` / `=`         | 放大 / 缩小 / 恢复原始大小                  |
| `Ctrl+r`                | 切换页面反色，适合夜间阅读                     |
| `f`                     | 显示链接编号，按提示选择要打开的链接                |
| `q`                     | 退出                                |
鼠标选中的文字能用 `Ctrl+V` 粘贴
在 Zathura 里输入 `:set selection-clipboard clipboard` 并回车。想让它每次启动都生效，就把下面这行写入 `~/.config/zathura/zathurarc`：

```
set selection-clipboard clipboard
```
